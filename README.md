# PISSTERIA feat. Uncle Pork

Single-file mobile-first 8-bit survivor game. Everything lives in `index.html`.

## Host on GitHub Pages
1. Push this folder to a repo.
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)`.
3. Share the `https://<you>.github.io/<repo>/` link. On iPhone: Share → Add to Home Screen for fullscreen.

## Tweaking
Balance numbers are in the `CFG`, `FORMS` and `DIFFS` objects at the top of the script. Speech-bubble lines are in `SAYS`.
